# 베타 0.1 — AMD·인텔 지원 추가패치 (한글패치 1.0 위에 덮는 방식)

## 배포 원칙
- **다른 사람이 만든 한글패치 1.0의 파일은 포함하지 않습니다** (`d3d9.dll`, 번역 데이터, 원본 `korfnt.dll`).
  사용자가 한글패치 1.0을 먼저 설치하고, 이 베타가 그 위에 덮어씁니다.
- 게임 원본 데이터도 포함하지 않습니다. 영문/기호 글꼴(원본 1~2페이지)은 사용자 PC의 Steam 원본에서 1단계 때 직접 추출합니다.
- 한글 글꼴 그림은 무료 글꼴(예: 나눔고딕, SIL OFL)로 그립니다 (`tools/gen_atlas_free.py`).
- 저장소에는 소스/스크립트/문서만 있습니다. 빌드된 `korfnt.dll`, 글꼴 그림(`kr_pages.dxt5`)은 저장소에 넣지 않습니다.

## 설치 흐름 (`beta/`)
1. `1_원본글꼴백업.bat` — 원본 상태에서 `data\pal_top.bin`(영문/기호 글꼴, 768×1152 DXT5) 추출.
2. 한글패치 1.0 설치.
3. `2_한글베타_적용.bat` — `PAL_FONTB0`(TOTEXP_P)과 디스크립터(TOTEXB_D)를 새 768×13248 아틀라스로 교체(아카이브 끝에 덧붙이고 목차 갱신), `"로이드 아빙"→"어빙"` 1바이트 수정, `korfnt\korfnt.dll`을 우리 DLL로 교체. 백업은 `korfnt_beta_backup\`.
4. `3_되돌리기.bat` — 한글패치 1.0 상태로 복구(TLDAT 길이 복원, 목차·DLL 복원, 오타 바이트 복원).

적용 전 검사: TLFILE.TLDAT 크기가 한글패치 1.0(1,110,752,596)과 다르면 중단합니다. 원본 Steam 크기는 1,076,997,569.

## 고친 문제와 원인 (logger16 → logger23, `src/korfnt_kr.c`에 누적)
| 증상 | 원인 | 수정 |
|---|---|---|
| 한글이 일본어 문자로 깨짐(logger15) | 한글 판정 상수 버그 | 판정 수정(logger16), imm≥0x80 비교를 `81 /r imm32`로 |
| 글자 간격 이상 | 길이 스텁이 ecx/edx 를 망가뜨림 | stub에서 edx/ecx 보존(logger17) |
| 화자 이름표 깨짐 | 26개 길이 규칙 지점 중 5곳(0x4D7D6C 등)이 한글에도 2-슬롯 마커를 건너뜀, 작은 글자 폭 함수가 바이트 단위 가정 | 건너뛴 부작용 명령 재현(logger18/19) |
| 점프 테이블 손상 | 주소 오타 `0x57ABA5`(정답 `0x557BA5`)로 0x556C3B 디스패치 테이블 59/60번 항목 덮음 | 오타 패치 제거(logger18) |
| 설정 설명칸 글자 깨짐 | 별도 함수(0x4F961E)가 한글을 1바이트씩 처리 | 길이 지점 0x4F9619 추가(logger20) |
| K 버튼 옆 행동명("대화한다") | 함수(~0x4D7466/0x4D77C0)가 1바이트=1글자 가정 | 글리프 인덱스→바이트 오프셋 매핑(logger21) |
| 음성 언어 일본어인데 인게임 영어 | 시작 시 설정 로드의 음성 설정 반영이 우리 패치로 깨짐. 음성 스위치(0xB1864E: 0=영어, 1=일본어)와 설정값이 다르면 게임 setter(0x583020)를 호출해 동기화 | logger23 |

### 음성 문제 원인 규명 방법
순정 Steam 설치(음성=일본어)는 정상 → 순정 + 우리 DLL만(원본 데이터)에서도 교실 영어 → 원인은 DLL, 데이터는 무관. 커스텀 설정 화면을 열면 setter가 불려 일본어가 되는 것도 같은 원인을 뒷받침.

## 알려진 점
- 설정 화면 항목명(Message Speed 등)은 게임 안에 그림으로 박혀 영어 그대로.
- 자동 입력 시험 중 교실 진입 약 2분 뒤 게임이 꺼진 적이 있으나, 수동 플레이에서는 확인되지 않았고 원인 미상(패치 이전부터 있었던 현상 포함 여부 불명).
- 글꼴은 무료 글꼴로 그려서 맑은 고딕판과 모양이 다릅니다. Release의 베타 0.1 zip은 Noto Sans KR, 다음 배포판은 나눔고딕(SIL OFL)으로 바꿀 예정이며 둘 다 게임 내 최종 확인 전입니다.
