테일즈 오브 심포니아 (Steam) 한글패치 AMD·인텔 지원 추가패치 — 베타 0.1 (2026-10-14)

■ 이게 뭔가요?
기존 "테일즈 오브 심포니아 한글 패치 1.0"은 NVIDIA 그래픽카드에서만 한글이 제대로 나옵니다.
이 추가패치를 한글패치 1.0 위에 덮으면 AMD / 인텔 / NVIDIA 모두에서 한글이 나옵니다.
※ 이 파일에는 한글패치 1.0의 번역·파일이 들어 있지 않습니다. 한글패치 1.0은 원 제작자 배포본을 따로 받으세요.

■ 설치 순서 (꼭 이 순서대로)
0. 이 베타 폴더를 게임 폴더(TOS.exe 가 있는 곳) 안에 통째로 넣으세요.
   예) D:\SteamLibrary\steamapps\common\Tales of Symphonia\한글베타\
1. [원본 상태에서] 1_원본글꼴백업.bat 실행
   - 게임 원본의 영문/기호 글꼴 부분을 이 폴더(data\pal_top.bin)에 백업합니다.
   - 이미 한글패치 1.0을 깔았다면: 스팀 → 게임 우클릭 → 속성 → 설치된 파일 → "게임 파일 무결성 확인"으로
     원본으로 돌린 뒤 1번을 하세요.
2. 한글패치 1.0 설치 (원 제작자 설명대로)
3. 2_한글베타_적용.bat 실행
4. 게임 실행

■ 되돌리기
3_되돌리기.bat 실행 → 한글패치 1.0 상태로 돌아갑니다.
완전히 원본으로 돌리려면 스팀 "게임 파일 무결성 확인" 후 d3d9.dll, korfnt 폴더 등 한글패치 파일을 지우세요.

■ 고친 것 (베타 0.1)
- 대사창 / 나레이션 / 메뉴 한글, 물음표 등 한글 기호
- 말하는 사람 이름표, 커스텀 설정 설명칸, K 버튼 옆 행동 안내(예: 대화한다)
- 음성 언어를 일본어로 해도 게임 안 음성이 영어로 나오던 문제
- 번역 오타 1곳: "로이드 아빙" → "로이드 어빙"

■ 알려진 점
- 커스텀 화면의 항목 이름(Message Speed 등)은 게임에 그림으로 들어 있어 영어 그대로입니다.
- 베타입니다. 이상한 곳이 있으면 스크린샷과 함께 알려 주세요.

■ 구성 / 라이선스
- korfnt\korfnt.dll : 한글 처리 패치 (소스 src\korfnt_kr.c, mingw32 gcc -DRELEASE 빌드)
- data\kr_pages.dxt5 : 한글 글꼴 그림. 무료 글꼴(SIL Open Font License)로 그렸습니다. 베타 0.1 = Noto Sans KR. (tools\gen_atlas_free.py)
- tools\*.ps1 : 설치/되돌리기 스크립트 (윈도우 기본 PowerShell 사용)
